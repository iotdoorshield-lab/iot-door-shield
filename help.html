❓ Frequently Asked Questions

How do I add a new family member to the system? ▼

To add a new family member:

  1. Go to Family & Friends page
  2. Click the "+ Add Person" button
  3. Enter the person's full name
  4. Select their relation (Family Member, Friend, etc.)
  5. Choose access level (Full/Limited/Temporary)
  6. Click "Add to Home"
  7. Have the person stand in front of the camera to capture their face

Note: Make sure the person is in good lighting and facing the camera directly for best recognition.

How do WhatsApp alerts work? ▼

The system sends WhatsApp alerts in these situations:

  • Unknown Person Detected: Photo + timestamp sent immediately
  • Door Forced Open: Alert when door is opened without recognition
  • System Alerts: Low battery, camera offline, etc.

To setup WhatsApp alerts:

  1. Go to Settings → Notifications
  2. Turn on "WhatsApp Alerts"
  3. Enter your WhatsApp number
  4. Choose which alerts to receive
  5. Save settings

You'll receive a confirmation message on your WhatsApp when setup is complete.

How long does face recognition take? ▼

Recognition speed depends on several factors:

  • Known person: 1-2 seconds
  • Unknown person: 2-3 seconds (includes alert processing)
  • Light conditions: Good light = faster recognition
  • WiFi speed: Faster internet = quicker alerts

For best performance:

  • Keep camera lens clean
  • Ensure strong WiFi signal
  • Use medium resolution setting
  • Regularly update face database
Can I give temporary access to delivery people? ▼

Yes! You can set up temporary access:

  1. Add the person as "Delivery Person" in database
  2. Set access level to "Temporary"
  3. Set specific time slots (e.g., 10 AM - 6 PM)
  4. Enable one-time access codes if needed

Features for delivery access:

  • Time-restricted access
  • Photo capture on entry/exit
  • Special alert notifications
  • Automatic removal after time expires
How do I backup my face recognition database? ▼

To backup your database:

  1. Go to Settings → Database
  2. Click "Backup Database" button
  3. Choose backup location (Cloud/Local)
  4. Set automatic backup schedule (Daily/Weekly)
  5. Add email for backup notifications

Backup Options:

  • Local Backup: Save to your computer
  • Cloud Backup: Automatic backup to secure cloud
  • Export CSV: Export names and access levels
  • Full System Backup: Settings + Database + Logs

🔧 Quick Troubleshooting

Problem: Camera showing black screen ▼

Solution:

  1. Check camera power connection
  2. Restart ESP32-CAM module
  3. Check WiFi connection
  4. Clean camera lens
  5. Update camera firmware
Problem: WhatsApp alerts not working ▼

Solution:

  1. Check internet connection
  2. Verify phone number in settings
  3. Check WhatsApp is installed
  4. Restart system
  5. Test with demo alert
Problem: Face recognition slow ▼

Solution:

  1. Improve lighting conditions
  2. Clean camera lens
  3. Update face database
  4. Check WiFi signal strength
  5. Reduce database size
